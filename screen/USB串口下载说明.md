# 不用 TF 卡下载屏幕程序

适用于 `TJC3224T132_011C__A01`。需要 USB 转 TTL 串口模块，例如 CP2102 或 CH340。普通 USB 线不能直接给这块四针串口屏下载；不要使用 RS232 电平转换器。

## 软件和工程

- 软件启动：`D:\TJC\Editor\USART HMI.exe`，已从官方包解压可运行。
- 原始下载包：`D:\TJC\Downloads\USARTHMIsetup_latest.zip`。
- 打开本目录 `environment-monitor-TJC3224T132.HMI`。
- 预编译下载文件为同名 `.tft`。不要把 STM32 的 `.hex` 下载到屏幕，也不要把 `.tft` 下载到 STM32。

## 接线

先断电，下载期间断开屏幕与 STM32 的 TX/RX 连接，防止两路发送端同时驱动同一根线。按屏幕背面丝印辨认引脚，不凭线的颜色判断。

| 屏幕引脚 | 连接 |
|---|---|
| GND | USB 转 TTL 的 GND，并与外部电源负极共地 |
| RX | USB 转 TTL 的 TXD |
| TX | USB 转 TTL 的 RXD |
| 5V | 稳定的 5V 电源正极 |

屏幕是 **5V 供电、3.3V TTL 串口电平**，两者不同。USB 转 TTL 的 TXD/RXD 使用 3.3V 逻辑，不要给屏幕 RX 输入 5V 信号，也不要把屏幕供电脚接到模块的 3.3V 输出。部分模块的跳线只切换供电输出，不切换串口逻辑，需核对模块说明。

官方规格书推荐 5V 1A 稳压电源，屏幕满背光典型电流 160mA。若使用独立 5V 电源，USB 转 TTL 的 VCC 悬空，只接 TXD/RXD/GND，避免两路电源正极并联。供电不足会导致重启或下载失败。

## 下载步骤

1. USB 转 TTL 插入电脑，确认设备管理器出现 COM 端口；缺驱动时安装对应芯片的官方驱动。
2. 给屏幕供电，打开上述 HMI，确认工程目标 `TJC3224T132_011`，横屏 320×240。
3. 在 USART HMI 点“编译”，应显示 0 错误、0 警告。
4. 点“下载”，选 USB 转 TTL 对应的 COM 口，首次可用自动识别或 115200 下载速率。实际选项以软件窗口为准；通信初始波特率为 9600，下载工具会协商传输速率。
5. 开始下载；如果软件提示给屏幕重新上电，按提示重启屏幕。等待完成，不中途断电或拔串口。
6. 下载后重启，应该出现“环境监测”首页。此时没有连接 STM32，显示占位值是正常的，可以先检查本地翻页和加减操作。
7. 断电，拆下下载器，再按主板接线恢复 STM32 与屏幕的交叉 TX/RX 及共地，进行整机联调。固件运行串口为 9600-8-N-1。

提示“连接失败”时依次检查：COM 是否选对/被占用、TX/RX 是否交叉、是否共地、5V 供电是否稳定、是否仍连着 STM32、是否需要按软件提示重新上电。尚未连接用户实物，本包不声称已经下载成功。
